spackon — 3-Stage Collaborative Workflow

ARCH HPC · Johns Hopkins University · $SPACK_DEPLOY_GROUP controls admin access · $SPACK_ADMIN_USER is master

⚙️ Stage 0: Setup  — master, once
mkdir /scratch/admin/spack
chmod 2775
chown master:SPACK_DEPLOY_GROUP
→
spackon --keys create
spackon --keys export
each admin runs once
→
spackon --keys trust
master approves all
exported keys
↓
🔨 Stage 1: Build  — any admin
export SPACK_ROOT=
/scratch/admin/spack
spackon
→
spack env create locally
spack add pkg@ver
spack concretize -f
→
spackon -i locally
SLURM: 8 cores / 4 h
builds into scratch
↓
